# Detecting Covert Real-Time AI Assistance in Video Interviews

Final year project — behavioral/latency/linguistic detection of covert
LLM-mediated answer assistance during video interviews, using a **two-stage
design**: Stage 1 computes population reference ranges (mean/std per feature)
from existing public datasets; Stage 2 trains and evaluates the detector on a
smaller purpose-collected, within-subjects volunteer dataset.

How the two stages relate (worth stating accurately in the thesis): Stage 1
z-scoring re-expresses features as "standard deviations from the population
norm", which is useful for interpretation and sanity checks. It does **not**
change classifier predictions — tree models are invariant to per-feature
rescaling and the logistic-regression pipeline re-standardizes per fold. The
normalization that does matter is **per-speaker centering** in Stage 2
(`src/modeling_utils.py`): each feature is expressed relative to that
volunteer's own average, so the model sees the within-person change between
conditions rather than stable individual differences.

See the full proposal doc for background, related work, ethics, and timeline.
This repo covers Subsystems B and C (data pipeline + detector model) from
Section 4 of that proposal.

## Running the pipeline, in order

All commands are run from the project root, but scripts no longer depend on
the working directory (paths are anchored in `src/paths_config.py`).

```bash
# 1. Stage 1 datasets live in external_data/ (or on the external drive — if
#    its letter changes, update EXTERNAL_DRIVE_ROOT in src/paths_config.py).
python src/pretrain_calibration.py --check-paths

# 2. Build the Stage 1 reference stats. Clips listed in data/labels.csv are
#    automatically excluded, and clips are randomly sampled (seeded).
python src/pretrain_calibration.py              # --max-latency 500 --max-linguistic 50 --seed 42
#    -> writes models/baseline_stats.json

# 3. Fill in data/labels.csv with your real volunteer clips (see
#    data/labels_template.csv). For clips trimmed per the session protocol,
#    set question_end_time = 0.0 — otherwise response_delay is lost.

# 4. Build the master feature table
python src/build_features.py

# 5. Train + evaluate (pooled out-of-fold metrics, speaker-bootstrap CIs, permutation test)
python src/train_model.py                       # --model xgb | --no-speaker-norm | --permutations N

# 6. Run the ablation study for your evaluation section
python src/evaluate_model.py                    # --permutations N to add p-values
```

**Note:** every `extract_*_features()` function works even before Stage 1
is run — `baseline_utils.py` falls back to raw (non-normalized) values if
`models/baseline_stats.json` doesn't exist yet. Whenever an extractor changes,
rerun step 2 and then step 4, so Stage 1 and Stage 2 values are computed the
same way.

## Important: leave-speaker-out, always

Every script here splits by `volunteer_id`, never by `clip_id`. Do not
change this — splitting by clip lets the model learn to recognize
individual faces/voices rather than the actual behavioral signature,
which would invalidate the whole evaluation (see proposal Section 4.4).

Report the **pooled out-of-fold** numbers printed by `train_model.py` /
`evaluate_model.py` (with their confidence intervals and permutation p-value),
not per-fold averages — each fold holds only one speaker's handful of clips.
